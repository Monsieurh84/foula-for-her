# FOULA for her

Maquette du site e-commerce de la maison de parfum **FOULA for her** — par une femme, pour les femmes.

Site en ligne : https://monsieurh84.github.io/foula-for-her/

## Contenu
- Accueil immersif : ouverture animée, les cinq femmes FOULA, collection, histoire, coffret découverte, diagnostic olfactif
- Une page par parfum : Minuit Passé, Elle Ose, C'est Elle, Secret de Femme, Belle Allure
- Contenances 30 ml · 50 ml · 100 ml, coffret découverte 5 × 2 ml, panier
- Pages service clientes : livraison, contact, FAQ, CGV, mentions légales, confidentialité

## Structure
```
index.html
assets/css/foula.css
assets/js/foula.js
assets/js/vendor/   (GSAP, ScrollTrigger, Lenis)
assets/img/         (flacons détourés, monogramme, logo)
assets/fonts/
```

Maquette de présentation, non indexée par les moteurs de recherche. La boutique finale sera montée sur Shopify.
